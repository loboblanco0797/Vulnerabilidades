
Vulnerabilidades: KEV Intelligence Dashboard 🛡️
Generador dinámico de reportes de inteligencia de amenazas basado en el catálogo KEV de CISA.Automatización para el análisis y filtrado de vulnerabilidades bajo explotación activa, diseñada para equipos de seguridad que requieren priorización basada en riesgo real.  📑 Nota TécnicaEl sistema prioriza las amenazas basándose en el catálogo KEV (Known Exploited Vulnerabilities) de CISA, el cual filtra el ruido de los miles de CVEs existentes para mostrar únicamente aquellos con explotación activa confirmada en entornos reales. Esto permite que el Dashboard funcione como una herramienta de toma de decisiones crítica para equipos de Red Team y Blue Team.
